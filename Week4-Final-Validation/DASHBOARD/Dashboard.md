# FinTrust Digital Bank — Power BI Dashboard

## 1. Dashboard Overview

This interactive Power BI dashboard was developed as part of the **FinTrust Financial Intelligence & Digital Banking Support Solution**, completed under the AnalystLab Africa Data Analytics Internship.

The dashboard presents key insights into customer and transaction activity, transaction performance, channel performance, domestic and international transactions, and risk-review patterns.

## 4. Dashboard Contents

The dashboard covers the following areas:

* **Transaction KPIs:** Overall transaction performance and key metrics.
* **Monthly Trends:** Transaction performance over time.
* **Channel Performance:** Comparison of transaction outcomes across channels.
* **Domestic vs. International Transactions:** Comparison of transaction activity and value.
* **Risk-Review Analysis:** Examination of transactions flagged for further review.
* **Interactive Analysis:** Slicers and chart interactions for exploring the available data.
