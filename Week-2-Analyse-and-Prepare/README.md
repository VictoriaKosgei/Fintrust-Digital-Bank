# FinTrust Digital Bank — Week 2: Analyse & Prepare

## Project Overview

Week 2 of the FinTrust Digital Bank Experience Lab focused on transforming the Week 1 business and data understanding into practical analysis.

The work covered data quality assessment, SQL business analysis, Python exploratory data analysis, Power BI dashboard development, and identification of meaningful business findings.

## Objectives

The main objectives of Week 2 were to:

- Assess and prepare the customer and transaction data
- Perform business-driven SQL analysis
- Conduct exploratory data analysis using Python
- Develop an initial management dashboard in Power BI
- Identify meaningful business findings
- Translate analytical results into business meaning

## Datasets

The project uses:

- FinTrust Customer Data
- FinTrust Transaction Data
- FinTrust Data Dictionary

### Dataset Overview

- Customers: 1,500
- Transactions: 12,000
- Total Transaction Value: approximately NGN 560.48 million

## Part A — Excel Data Quality & Cleaning

The Excel workbook was used to assess:

- Number of records
- Number of columns
- Missing values
- Duplicate records
- Data types
- Inconsistent values
- Unusual values
- Potential outliers
- Customer–Transaction relationship

## Part B — SQL Business Analysis

SQL was used to answer eight business questions covering:

1. Customer behaviour
2. Transaction activity
3. Transaction value
4. Transaction types
5. Transaction channels
6. Transaction status
7. Customer segments
8. Risk-review patterns

Each question was analysed using SQL and interpreted from a business perspective.

## Part C — Python Exploratory Data Analysis

Python was used to explore:

- Customer segments
- Transaction types
- Transaction amounts
- Transaction channels
- Transaction status
- International transactions
- Customer behaviour
- Risk-review patterns

Tools used:

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Part D — Power BI Dashboard

- Risk-review activity
- Changes in transaction activity over time
